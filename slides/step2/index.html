テストエンジニア育成講座 Step2（応用編）

一人で回せるエンジニアから、戦略を選び、チームとAIに品質を広げるエンジニアへ — 全3回 / 各90分

第4回（90分）

テスト戦略とリスクベースドテスト — 「全部やる」から「賢く選ぶ」へ

テストアプローチの選択、リスク分析と濃淡設計、探索的テスト入門。「戦略を選ぶ」力を作る。

 第5回（90分）

シフトレフトと上流品質 — テスト実行前に品質を作り込む

レビュー技法、受け入れ条件と実例マッピング、アジャイルQA。「上流から品質に関与する」力を作る。

 第6回（90分）

テスト自動化とAI時代のQA — 実行者から品質の設計者へ

自動化の判断軸、AI×QAの現在地マップ、QAの仕事はどう変わるか。キャリアの地図を持って卒業する。

Step2の進め方

  • Step1（第1〜3回）の修了を前提とします。例題は引き続き「経費精算システム」です。
  • ツールの操作方法ではなく「判断軸」を扱います。手順は現場のOJTで身につけます。
  • 体系は ISTQB Advanced Level（Test Analyst / Test Manager）と CT-AI / CT-GenAI の入口に対応しています。
  • 最終回のあとに、リスク分析からAI活用までを通しで行う卒業課題があります。
